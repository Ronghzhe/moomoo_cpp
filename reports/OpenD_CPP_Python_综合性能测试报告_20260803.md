# OpenD C++ / Python 性能对比报告

> 2026-08-03～04 | OpenD `127.0.0.1:11121` | Python SDK vs C++ SDK 直连

---

## 结论

在同机 OpenD 直连对比下，**C++ 各环节均快于 Python**：

- **行情链路**（K 线、推送）：与模拟盘/实盘无关，C++ 约快 **1.5～2.4 倍**
- **模拟盘交易**（下单、推送、查单、撤单）：C++ 约快 **1.4～1.5 倍**，下单约省 **15～18 ms**
- **实盘往返**（HK.02208，**实测 10 次**）：C++ 仍快于 Python，方向与模拟盘一致

---
